# proxyindex-site

Готовая статика сайта ПроксиИндекс (https://proxyindex.ru) — публикуется через GitHub Pages (ветка main, папка `docs/`).
Руками не править: папка `docs/` перезаписывается при каждой выкладке
(`~/таск трекер/autopilot/ap.py deploy proxyindex` или публикация статьи).
Исходники и сборка — `~/таск трекер/proxy_rating`. `render.yaml` — временное зеркало на Render.
