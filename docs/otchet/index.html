Для сервисов из рейтинга

Каждый сервис из рейтинга может поставить на свой сайт значок с местом — он ведёт на карточку сервиса, где видно, какие условия подтверждены. Значок называет место ровно так, как оно опубликовано. Код для своего места — внизу страницы сервиса. Исправления и заявки на включение — на data@proxyindex.pro.
